# Precio de la luz hoy

Precio del PVPC por horas para hoy y mañana: hora más barata y más cara, media del día, mejores horas para la lavadora, el lavavajillas, el horno o el coche eléctrico, y lo que cuesta cada aparato a cada hora.

Sitio: https://adrianezd.github.io/precio-luz-hoy/

- HTML, CSS y JS estáticos, sin build.
- Los datos se piden en el navegador a la API pública REData de Red Eléctrica (`apidatos.ree.es`, con CORS abierto). No hay ninguna cifra escrita a mano: si la API no responde, la página lo dice.
- El precio de mañana aparece cuando Red Eléctrica lo publica, hacia las 20:30.
